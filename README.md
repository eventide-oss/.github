# Eventide

Eventide is an open source organization building infrastructure and
developer tooling for the cloud-native ecosystem, written in Go.

## What we believe
- **Open by default**: Apache 2.0, public roadmap, transparent decisions.
- **Built to be used**: every project solves a real problem teams face today.
- **Community first**: welcoming to first-time contributors, with clear
  guidelines and mentorship.

## Projects
- **[Vesper](https://github.com/eventide-oss/vesper)**: a Kubernetes operator
  and CLI (`vesperctl`) that creates ephemeral preview environments for
  every pull request and cleans them up automatically.

## Get involved
Read our CONTRIBUTING guide, pick a `good first issue`, or open a discussion.
All contributions are welcome: code, docs, ideas, and feedback.
